MIS RECORDATORIOS V1

Incluye:
- Crear, editar y eliminar recordatorios.
- Fecha y hora.
- Repetición diaria, semanal y mensual.
- Pendientes, Hoy, Todos y Completados.
- Búsqueda.
- Notificaciones del navegador cuando están permitidas.
- Almacenamiento local.
- Modo oscuro.
- Instalación como PWA.

INSTALACIÓN:
1. Sirve esta carpeta desde HTTPS o localhost. Una PWA normalmente requiere HTTPS para instalarse y usar service workers.
2. En Android abre la dirección en Chrome.
3. Pulsa "Instalar app" o "Agregar a pantalla de inicio".
4. Activa las notificaciones.

NOTA:
La V1 guarda los datos en el dispositivo. Si borras los datos del navegador o desinstalas/limpias el almacenamiento, los recordatorios locales pueden perderse. La siguiente versión puede añadir exportación/importación y sincronización.
